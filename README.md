# \## Дүгнэлт (Хэсэг E)

# Энэхүү лабораторийн ажлаар Уншлагын жагсаалт вэб аппликейшнд SBTM аргыг ашиглан exploratory тест хийлээ. Туршилтын явцад номын жагсаалт авах API-ийн ажиллагааг шалгахад HTTP 200 OK статус буцаж, гурван номын мэдээлэл амжилттай ирсэн. Харин номын тоолуур шалгахад жагсаалтад гурван ном байхад нийт номын тоо дөрөв гэж буцаж байгаа алдаа илэрсэн. Хамгийн сүүлд хэвлэгдсэн оныг харуулах `newest` утга 2008 гэж зөв гарсан. Туршилтын үр дүнд API-ийн хариу болон өгөгдлийн зөв байдлыг шалгах нь чухал болохыг ойлгосон. Мөн серверийг Node.js ашиглан ажиллуулж, `curl` командаар API хүсэлт илгээж сурлаа. Илэрсэн алдааг тэмдэглэж, цаашид шалгах шаардлагатай хэсгүүдийг тодорхойлсон. Дараагийн туршилтаар буруу JSON хүсэлт, хоосон талбар, хүчингүй он болон хайлтын ажиллагааг шалгах шаардлагатай. Ерөнхийдөө энэхүү лабораторийн ажил нь програмын алдааг хэрэглэгчийн өнцгөөс илрүүлэх, тестийн үр дүнг баримтжуулах чадварыг нэмэгдүүлсэн.



\## Аппликейшнийг ажиллуулах



1\. Төслийн хавтас руу орно.

2\. `node app.js` командаар серверийг ажиллуулна.

3\. Хөтөч дээр дараах хаягаар нээнэ.
